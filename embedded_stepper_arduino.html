1. Introduction and objectives

Definition. An embedded system is a computer (microcontroller, SoC or DSP plus firmware) built into a larger product to perform one dedicated function, usually under real-time, power, size and cost constraints.

Principle: sensors → processor running firmware → actuators/communication. An Arduino Uno (ATmega328P, 16 MHz, 5 V logic) is a beginner-friendly embedded board. A stepper motor converts digital pulses into fixed angular steps, so position is controlled by counting pulses.

Prerequisites: digital logic, transistor switching, inductors and back-EMF, basic C. Terms: step angle, steps/rev, full-step, half-step, microstepping, holding torque, open-loop control, flyback diode.

Arduino sketch

#include <Stepper.h>
const int SPR = 2048;                 // full steps per revolution
Stepper myStepper(SPR, 8, 10, 9, 11); // IN1, IN3, IN2, IN4 order
void setup() { myStepper.setSpeed(10); }   // RPM (keep ≤ ~15)
void loop() {
  myStepper.step(SPR);  delay(1000);       // one revolution CW
  myStepper.step(-SPR); delay(1000);       // one revolution CCW
}

4. Working principle

  1. Firmware energises coils in a repeating sequence; the rotor aligns with each energised stator pole.
  2. Each output pin turns a Darlington transistor on, grounding that coil end; current flows from +5 V through the coil.
  3. When a coil is switched off, its stored energy L·di/dt creates a voltage spike; the ULN2003 clamp diodes absorb it.
  4. Reversing the sequence reverses rotation. Delay between steps sets speed; step count sets angle.
ModePatternEffect
Wave driveOne coil on at a timeLowest torque and current
Full stepTwo coils onHigher torque (≈1.4×)
Half step1, 2, 1, 2 coils alternatingDouble resolution, smoother
MicrostepPWM-shaped coil currents (A4988/DRV8825)Finest resolution; torque per microstep reduced

DC vs AC view: DC holds the rotor (holding torque, coils stay hot); the switching sequence is the AC drive. Limits: torque falls with speed because coil inductance slows current rise (τ = L/R); excessive step rate causes missed steps. Misconceptions: (a) the Arduino pin cannot drive the motor directly (40 mA absolute max per pin vs ≈100 mA per coil); (b) position is open loop, so errors only appear if steps are lost; (c) a motor that is stationary but energised still draws current.

6. Equations

Step angle: θs = 360° / N   (N = steps per revolution)
Steps for rotation θ: n = θ / θs
Speed: RPM = (fstep × 60) / N   ⇒ fstep = RPM × N / 60
Delay per step: td = 1 / fstep
Microstepping: Neff = N × m   (m = microsteps per full step)
Coil current: I = V / Rcoil; Power: P = I²R (per energised coil)
Electrical time constant: τ = L / R

Derivation of speed: fstep steps per second ÷ N steps per rev = revolutions per second; ×60 gives RPM. Units: f in Hz (steps/s), N dimensionless steps, RPM in rev/min. Valid while the motor tracks each pulse (no stall); limiting case: as f → very high, torque → 0 and steps are lost. Physical meaning: speed is set purely by the pulse rate in open loop.

7. Solved numerical problems

Problem 1 (easy). A hybrid stepper has θs = 1.8°. Find N and the steps for 90°.
Required: N, n. Formula: N = 360°/θs; n = θ/θs.
N = 360°/1.8° = 200 steps/rev; n = 90°/1.8° = 50 steps.
Interpretation: a quarter turn needs 50 pulses.
Problem 2 (moderate). 28BYJ-48 (N = 2048) must run at 10 RPM. Find fstep and delay.
f = RPM·N/60 = 10 × 2048 / 60 = 341.33 steps/s; td = 1/341.33 = 2.93 ms.
Interpretation: a delay under about 2 ms (≈ 15 RPM) makes this geared motor skip steps.
Problem 3 (GATE-style). A 200-step motor uses a driver with 1/16 microstepping and must turn at 60 RPM. Find the pulse frequency.
Neff = 200 × 16 = 3200. f = 60 × 3200 / 60 = 3200 Hz; resolution = 360°/3200 = 0.1125°.
Shortcut: when RPM = 60, f(Hz) equals Neff numerically. Interpretation: the Arduino must produce a 3.2 kHz pulse train, easily done with a timer.
Problem 4 (current check). Coil R = 50 Ω at 5 V. I = 5/50 = 0.1 A = 100 mA, which exceeds the 40 mA absolute maximum of an ATmega328P pin, so a driver (ULN2003 rated 500 mA) is mandatory. With two coils on, supply current ≈ 200 mA, P = 5 V × 0.2 A = 1 W.

9. Core-company interview preparation

Industry perspective: in real projects the Arduino-class prototype is replaced by an MCU (STM32, PIC, NXP) with a dedicated stepper driver IC, timer-generated pulses with acceleration ramps, current limiting, and validation on a hardware-in-the-loop bench.

10. Applications and industry relevance

AreaUse of stepper / embedded control
3D printers, CNCAxis positioning with microstepping drivers
MedicalSyringe and infusion pumps, analyser sample handling
AutomotiveInstrument-cluster needles, HVAC flap actuators
Consumer/officePrinters, scanners, camera autofocus
IndustrialValve control, conveyor indexing

Advantages: low-cost open-loop positioning, high holding torque, digital interface. Limitations: missed steps without feedback, resonance, heat at standstill, torque drop at speed. Challenges: mid-band resonance, supply sag, noise on logic lines. Roles: firmware engineer, embedded systems engineer, hardware validation, motor-control and automation engineer.
